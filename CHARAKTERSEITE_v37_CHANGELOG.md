# VALDARA Frontend v37 – Charakterseite

- Ergänzt ein Feld „Deine Geschichte“ mit bis zu 12.000 Zeichen.
- Die Geschichte wird in `public.characters.character_story` gespeichert und kann wiederholt bearbeitet werden.
- Nach vorhandener Volk-/Avatar-Auswahl und gespeicherter Geschichte erscheint die Charakterseite statt des Einrichtungsbereichs.
- Über „Charakter bearbeiten“ können Profil, Volk, Avatar und Geschichte erneut geöffnet werden.
- Der Menüpunkt „Profil“ wird bei angemeldeten Benutzern in der Hauptnavigation eingeblendet.

## Wichtig vor dem Upload
1. `CHARAKTERGESCHICHTE_v37.sql` im Supabase SQL Editor ausführen.
2. Anschließend die aktualisierten Frontend-Dateien aus diesem Paket deployen.

Die Änderung wurde lokal in der v36-ZIP vorgenommen; sie wurde nicht automatisch auf Cloudflare oder Supabase veröffentlicht.
